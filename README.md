# 同桌 · 朋友德州

一个固定房间，PC 浏览器使用。原生 HTML / CSS / JavaScript + Node.js，无第三方依赖。

- 最多 9 人，名字 + 入口令入座。管理员使用管理员密码入座。
- 每次整场开始每人 1000 分；固定盲注 10/20。输光下场，本场不能补分。
- 无限注规则，自动庄家轮换、边池、All-in、平局分池。45 秒超时自动过牌或弃牌。
- 本手结束展示 7 秒，然后继续。整场只剩一位有分玩家时结束。
- 管理员可开始、结束、修改入口令；未开场可移除不用的座位。
- 局中加入等待下一整场；修改口令只影响之后加入的玩家。
- 管理员结束时，未完成手牌的下注全部退还；已结算结果保留。
- 保留最近 300 条牌桌记录；刷新或重启后通过原浏览器身份恢复。
- 仅积分娱乐学习，无任何充值、提现、奖金或筹码交易功能。

## 本机启动

安装 Node.js 22 或更新版本，然后在项目目录执行：

```sh
npm start
```

打开 http://localhost:3000。首次运行终端显示“初始化密钥”，用它设置管理员密码（至少 8 位）和分享入口令（至少 4 位）。管理员登录勾选“我是管理员”，用管理员密码；朋友使用入口令。

同一浏览器的标签页共用一个身份，多人测试请用不同浏览器或独立浏览器配置。身份保存在 HttpOnly Cookie 中；误关页面后重新打开同一个网址，会直接恢复原来的名字和座位。换浏览器或清除身份后，可输入原名字和当前入口令恢复离线座位：服务器确认旧连接关闭后保留约 5 秒重连缓冲，页面会自动等待重试。仍在线的名字不可接管；一个标签页关闭但另一个仍连接时也算在线。管理员座位需要勾选管理员并使用管理员密码恢复。恢复保留原积分、当前手牌、已下场状态和等待状态，不重新发 1000 分；旧浏览器凭证会失效。

局域网可以访问 `http://运行电脑的局域网IP:3000`。公网部署使用下方 HTTPS 方式。

## Linux 部署

2 核 4G、1Mbps 带宽足够一桌使用。需要 Node.js 22+，建议 Nginx + HTTPS。无需数据库、npm install 或前端构建。以下假设 Node 位于 `/usr/bin/node`（先用 `command -v node` 核实并修改 service 文件）。

上传项目到 `/opt/friends-holdem`，不要上传本机 `data` 目录。然后：

```sh
sudo useradd --system --home /opt/friends-holdem --shell /usr/sbin/nologin holdem
sudo cp /opt/friends-holdem/deploy/friends-holdem.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now friends-holdem
sudo journalctl -u friends-holdem -n 30 --no-pager
```

从日志获取首次初始化密钥。把 `deploy/nginx.conf` 中域名换成自己的，放进现有 Nginx 的站点配置并检查 `sudo nginx -t` 后 reload。用现有证书或 Certbot 配置 HTTPS，再通过 HTTPS 网址打开初始化。service 中默认 `SECURE_COOKIE=1`，只允许 HTTPS 浏览器保存身份；如仅局域网 HTTP 试用，改为 `0`。安全组开放 443 及证书签发所需的 80，3000 只监听本机供反向代理。

如果暂时没有域名，也可直接在项目目录 `HOST=0.0.0.0 PORT=3000 node server.js` 试用 IP 访问；正式分享建议启用 HTTPS，避免密码和底牌在传输途中被读取。

状态文件位于 `/var/lib/friends-holdem/state.json`，包含密码摘要、牌局及浏览器身份，请仅管理员可读。不要对外提供该目录。默认本机开发状态位于 `data/state.json`，已加入 gitignore。服务正常退出和每次操作都会持久化；单实例运行，不要开多个 Node worker。

规则测试：`npm test`。

基本下注与摊牌规则参考 [Poker TDA 规则](https://www.pokertda.com/view-poker-tda-rules/)，软件自动处理行动顺序，无实体牌桌中的口头下注或误操作裁定流程。

## 已知边界

只做好友单桌，不含账号系统、机器人、聊天、比赛、支付和无限历史。已入座玩家可以持续查看牌局，修改入口令不会踢掉现有玩家。断线会继续计时，服务器恢复后到期行动会自动处理。部署公网需要提供服务器访问方式；仓库中的配置本身不表示已部署。

## 浏览器独立弹窗

点击页面的“独立窗口”，直接使用 window.open 打开浏览器精简弹窗，不需要下载或安装客户端。小窗口在顶部 ☰ 菜单中找到该按钮。

请求整个窗口（含标题栏、边框）为 400×300，可继续手动调整。是否隐藏地址栏等工具栏、允许多小的窗口，由浏览器决定；网页不强制锁定最小尺寸。重复点击会复用同一个牌桌弹窗。

弹窗与原网页使用同一个浏览器身份，名字、座位和积分自动恢复，不需要重复加入。若被浏览器拦截弹窗，允许此网站的弹窗后再点击。
