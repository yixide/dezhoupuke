# 同桌 · 朋友德州

一个供好友使用的单房间德州扑克小游戏，支持最多 9 人通过浏览器联机。使用原生 HTML / CSS / JavaScript 和 Node.js，无第三方依赖，无需数据库或前端构建。

仅用于积分娱乐和学习，不提供充值、提现、奖金或筹码交易。

## 功能

- 每场初始 1000 分，盲注从 10/20 开始，每 5 手上涨一档（下一手生效），支持无限注、All-in、边池和平局分池。
- 管理员管理牌局和访问口令；玩家凭名字和口令加入。
- 玩家可申请补分，管理员同意或拒绝；手牌进行中批准的补分在本手结算后到账，不改变当前 All-in 或边池。
- 支持 1/4 池、1/3 池、1/2 池和满池快捷加注，自动遵守最小加注和剩余积分限制。
- 玩家可随时主动亮出任意一张或两张底牌，未选中的牌继续保密；亮牌不改变行动顺序。
- 管理员点击“结束并重置”后，所有玩家立即恢复为 1000 分（包括离线、已下场和中途加入者），撤销未完成手牌，保留座位、口令和历史记录。自然结束后也可单独点击“重置积分”，无需等两人在线或再次开场。
- 自动轮换庄家、超时操作、连续超时暂离，支持中途加入和断线恢复。
- 牌局自动保存，支持记录查看、快捷聊天、语音提示和浏览器独立小窗口。

## 本地运行

安装 Node.js 22 或更新版本，在项目目录运行：

```sh
npm start
```

打开 [http://localhost:3000](http://localhost:3000)。首次启动时，终端会显示初始化密钥；在页面输入该密钥，设置管理员密码（至少 8 位）和访问口令（至少 4 位）。管理员勾选管理员身份登录，其他玩家使用访问口令。

同一浏览器的标签页共用身份，多人测试请使用不同浏览器或独立配置。刷新页面会恢复座位；换浏览器时，可在原连接离线后用原名字和当前口令恢复。中途加入的玩家从下一手参与。

## 补分、快捷加注与主动亮牌

- **补分**：操作区点击“申请补分”，输入 1～100,000 的整数。每人同时只能有一条待审批或待到账申请。管理员在同一入口查看申请列表，点击“同意”或“拒绝”。审批状态和到账结果实时同步并保存；普通玩家无法调用审批接口。未开场或本手已结算时立即到账；本手进行中则在结算后到账，已下场玩家补分后可从下一手重新参与。开场前已批准的补分会附加到新一场的基础 1,000 分上。
- **重置**：“结束并重置 / 重置积分”仍把所有玩家恢复到 1,000 分，并取消待审批、待到账申请；移除座位也会取消该玩家未完成的申请。
- **快捷加注**：点击比例按钮即提交加注。本次投入 = 向上取整（当前底池 ÷ 比例分母），例如底池 100、需跟注 20，满池本次投入 100。服务器按实时底池计算，并遵守最小加注和剩余积分限制；按钮展示实际投入及“最小加注 / All-in”限制。加注拖条按当前小盲的整数倍移动；不足一档时可使用独立 All-in 按钮。
- **亮牌**：点击“亮牌”，选择第一张、第二张或两张后确认，也可直接点击“亮出两张”。未轮到行动、已弃牌或本手结算后均可操作。公开后本手内不能收回；新一手恢复隐藏，过期亮牌请求不会误公开新手牌。系统自动摊牌规则保持不变。

- **涨盲**：第 1～5 手为 10/20，第 6～10 手为 20/40，第 11～15 手为 30/60，后续小盲依次为 50、100、150、200、300、500、1000、1500、2000、3000、5000、10000、20000、50000、100000，大盲为两倍；最后一档封顶。进行中的手牌不变，结束重置后重新从 10/20 开始。
- **头像互动**：每人随机分配并保存名字背景色，点击头像可扔鸡蛋或送花，全桌同步动画，每人每 3 秒一次，不扣积分。
- **行动提醒**：当前行动座位持续光圈和“请操作”标记，自己回合显示醒目横条、倒计时和页面标题；每 6 秒提醒一次，最后 10 秒每 3 秒一次，操作后停止并遵守静音。All-in 玩家头像持续冒火至本手结算，减少动态效果偏好下改为静态标记。
- **按住说话**：按住“🎙 按住说话”实时向同桌其他玩家发言，松开即关闭麦克风；单次最多 30 秒，同一时间一人发言。支持鼠标、触屏以及聚焦后的空格 / 回车；切到后台、失焦、掉线或设备断开时停止。首次需允许麦克风，必须使用 HTTPS（本机 localhost 可测试）。其他玩家点击页面后即可收听，独立“收听”按钮控制玩家语音；与游戏音效静音互不影响。服务器只实时转发，不保存录音，不将音频写入历史记录；断线重连不回放旧声音。
- **声音**：下注使用轻筹码声，过牌敲桌、弃牌和发牌使用纸牌声，结算和表情有独立短音效；仅快捷聊天播报语音，优先选择系统可用的自然中文声音。点击扬声器可静音，偏好保存在本机。音效在浏览器本地合成，无需下载或外部服务。

这些功能兼容已有 `data/state.json`，无需清空原有数据。管理员密码、入口令、玩家积分和会话继续使用原有存储。

运行测试：

```sh
npm test
```

本地机器人陪练运行 `npm run practice`，打开 `http://localhost:3002/`。只监听本机，使用独立的 `data/local-practice/` 数据；练习用口令保存在该目录的 `credentials.json`，不会提交到仓库。管理员开始后，两位机器人每次思考 5～7 秒，再自动跟注、过牌或少量加注。玩家最近一次操作保留到他再次行动或本手结束，只显示操作本身，不显示轮次前缀或“待行动”；“庄”表示庄家，“先手”表示本轮第一个行动的人。

每轮下注完成后停留 3 秒，保留最后一人的操作及本轮下注，再发下一轮公共牌或摊牌。展示期间不允许操作，也不消耗下一位玩家的行动时间；全员离线时展示计时一起暂停。

## 部署

项目提供 [systemd 服务示例](deploy/friends-holdem.service) 和 [Nginx 配置示例](deploy/nginx.conf)。Linux 上将代码放入 `/opt/friends-holdem`，创建 `holdem` 系统用户，核对服务中的 Node 路径，再安装并启动服务：

```sh
sudo useradd --system --home /opt/friends-holdem --shell /usr/sbin/nologin holdem
sudo cp deploy/friends-holdem.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now friends-holdem
sudo journalctl -u friends-holdem -n 30 --no-pager
```

将 Nginx 示例域名替换为自己的域名并配置 HTTPS。服务示例仅监听回环地址，使用安全 Cookie，并信任本机 Nginx 提供的真实客户端 IP。通过日志获取首次初始化密钥后，在 HTTPS 页面完成设置。

常用环境变量：

| 变量 | 说明 |
| --- | --- |
| `HOST` / `PORT` | 监听地址和端口，默认 `0.0.0.0:3000` |
| `DATA_DIR` | 状态目录，默认项目下的 `data/` |
| `SECURE_COOKIE` | HTTPS 部署设为 `1` |
| `TRUST_PROXY` | 使用本机 Nginx 反向代理时设为 `1` |
| `SETUP_KEY` | 可选初始化密钥，默认启动时随机生成 |

实时语音使用已有 SSE 连接和短 HTTP 请求，单声道 16 kHz PCM，约 32 KB/s / 听众；反向代理须关闭缓冲并允许至少 8 KB 请求体。无需额外语音端口、WebRTC TURN 或外部语音服务。

仅支持单实例运行，不要启动多个 worker 共用同一状态文件。

## 数据与隐私

`data/state.json` 保存密码摘要、玩家信息、牌局和会话凭证。部署示例将其放在 `/var/lib/friends-holdem/`。这些数据只应由服务管理员访问，备份也应妥善保管。

运行数据、日志、环境变量文件、密钥、截图和本地打包文件已加入 `.gitignore`。请勿提交真实口令、初始化密钥、会话 Cookie 或部署凭证；公网使用 HTTPS，并仅通过 Nginx 暴露服务。
